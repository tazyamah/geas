# 名前と用語の選定理由

Geas の名前と用語は、意味と参照している概念から総合的に決めた。ここに理由と、避けた候補を残す。決めた日は 2026-10-26。

## 基準

- 名前に込める意味：約束を守らせる言語。計画書とコードを突き合わせて、言ったとおりに作れているかを機械で保証する（照合が核）。
- 標準の語と意味がずれていて、そのずれが間違いのもとになる語だけ、独自の名前にする。ずれが小さい語は標準の語を使う。
- カタカナで4字程度、日本人が読める、カタカナで読んだときに別の語に聞こえない。
- 契約・法の語彙で世界観を揃える。

## 確定した名前

| 日本語 | 名前 | 理由 |
|---|---|---|
| 言語名 | **Geas**（ギアス） | アイルランド伝承の geis。守らねばならない誓いと禁忌。「制約と誓約」。制約を重くするほど保証が強くなる、という言語の発想に合う。読み方は「ギアス」 |
| 内部の用語 | **Pledge** | 誓約。エンジン・ルール・説明に出てくるかもしれない程度の優先度。実際に出るとは限らない |
| 処理 | **Deed** | 行いであり、証書でもある。副作用を宣言して守る単位に合う |
| 参照 | **Slot** | 外から差し込む口。Given は入力と環境の向きを誤読されやすいので避けた |
| 束 | **Bond** | 結びつきと、証文の二重の意味。複数の外部作用を結んだ1つの約束（全部成功か全部失敗） |
| フロー | **Nexus** | 法律用語で、行為と結果の因果のつながり。Deed と次の Deed をつなぐ役を表す |
| データへの参照型 | **ref** | 【参照】を Slot にしたので、重複を避けた |

「結果の行き先に抜けがない」という検査は、アプリ全体の責務で、Nexus（フロー）の責務ではない。

## 名前の衝突（2026-10-26 時点の調査）

- crates.io：`geas` は空いている。
- npm：`geas` は2024年に作られた中身のない仮のパッケージ。
- PyPI：`geas` がある。OpenAPI からテスト用の契約を生成する Python のツール。分野が近いので、Python 側で名前を出すときは注意する。
- GitHub：検索できず、未確認。

## 作る側の注意

- 名前は意味を持たせて決める。決め直すときは、ここに理由を足す。
- 「Code Geass」は有名な作品の題名と重なる。公開するときは、権利の面を確かめる。

## ケルトの語に寄せる案（見送り）

geas の出どころがケルトの伝承なので、用語をケルトの語に寄せられるか調べた。意味がずれて誤読のもとになるときだけ独自名にする基準に照らすと、次の理由で見送った。

- Deed もケルト由来ではなく、法律用語（証書・行為）である。
- フローを Braid（組み紐）や Ogham（オガム文字）にする案は、形や文字からの見立てで、「結果でつながる連なり」という意味を持たない。ケルトの語としての根拠も弱い。
- Saga は、マイクロサービスの saga パターン（失敗時の巻き戻しで結果を保つ）と誤読されるため避けた。

フローは意味が合う Nexus のままにする。

## ツール名の候補（v0.1.0 で名前を決めるときに使う）

ケルト神話の語から。検査器は Brehon（古代アイルランドの法の裁定者）、生成器は Smith（神の鍛冶 Goibniu から）、記録の保存は Annals（年代記）。Táin は taint と、Cycle は繰り返しと紛れるので避ける。
