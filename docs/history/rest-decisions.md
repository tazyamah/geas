# REST の決めた日

[rest.md](../rest.md) の本文から移した。現在の決まりは本文を見る。

## 決めた日

| 日 | 決めたこと |
|---|---|
| 2026-10-28 | リソースと 5 つの動作、PATCH なし、命令の名詞化、入れ子は親の子だけ、結果ごとの HTTP の状態 |
| 2026-11-13 | 集まりの和と差は入れない（リソースを細かく切る） |
| 2026-11-16 | POST は URL が増えるときだけ。候補は `.geas` に直に書いて名前を付ける。絞り込みの条件は `q[名前]=値`（パスに並べない、クエリ文字列を並べて書かない） |
| 2026-11-16 | PUT と DELETE は If-Match 必須（行の版。無ければ 428、違えば 412） |
| 2026-11-16 | 続きの位置も並び順も `q` に入れる（検索リソースは論理的なリソースで、`q` の値は保存してある行と 1 対 1 ではない）。URL に載せられない条件（長い、ログに残したくない）は、本来 GET の問い合わせを、理由を書いて POST で受ける。条件は保存せず、その場で結果を返す |

2026-10-28 には「クエリ文字列は使わない」と決めていましたが、2026-11-16 に、絞り込みの条件に限って `q[名前]=値` の形だけを認めることにしました。
