# 後で検証すること

人が読むメモで、強制力は検査器にある。

## 最初の仕様書①を、geas を使わずに作る意味はあるか（2026-10-28 tazyamah）

今の流れは、①会話で仕様書を作る → ②それに従って geas を書く → ③geas から仕様書を生成して①と比べる。

宿題は、①を別に作るだけのメリットがあるのかを、あとで確かめること。人が1つの完全な仕様書をレビューする点は、①を別に作っても作らなくても変わらない。①を作らず、geas から生成した仕様書を直接レビューする流れでもよいのかもしれない。

変わらないこと：仕様書を比べる仕組みは、更新したときの差分を確認するために要る。geas 自体への要件は変わらない。

確かめ方の案：①を作る手間と、突合で見つかった食い違い（種類と数）を比べる。
