# Japanese / English mode

> This page is a translation of the Japanese original (the Japanese text is the source of truth).

The text geas outputs can be produced in either Japanese or English. **If you specify nothing, it is English** (the default for other people using it). To get Japanese, use one of the following.

```sh
geas check app.geas --lang ja        # Japanese just once (--lang=ja also works)
export GEAS_LANG=ja                  # Japanese always (put it in your shell settings)
```

The order of precedence is `--lang`, `GEAS_LANG`, then the default (English). Anything other than `ja` and `en` (forms such as `ja_JP.UTF-8` and `en-US` are accepted) is refused with exit code 2.

## What is switched

| Target | What is switched |
|---|---|
| Checker, syntax errors, CLI display | Messages, how-to-fix hints, `message` and `hint` of `--json` |
| Generated specifications, review screens, reports | Headings, table column names, fixed phrasing (also `<html lang>`) |
| Generated Rust and the app's parts | Run-time error text, fixed wording on screens (fixed to the language at generation time) |
| Display names (`///`) | Of `@en …` and `@ja …`, the one for the current language. If absent, the line without a tag, and finally the other language |

What is not switched:

- **Names in the code, and strings written by the user** (the body of `///`, strings on screens, values in examples, etc.). In the specification they appear in the language they were written in (this is why Japanese names appear in an English specification). When you need an English display name, add it like `/// @en Stock count`.
- **The plan (plan.md).** The reading used for matching is tied to Japanese headings, so the plan and its template (`geas interview`) are Japanese for now.
- `astdump` and the development output (`rustlib`, `rusthost`). Other tools read them, so they stay Japanese always.
- When using `geas_core` as a library, the default is Japanese (switch with `geas_core::i18n::set_lang(Lang::En)`).

## How it works

The source of the wording is written in Japanese in `crates/geas-core/src`, and only in English mode it is turned into English right before output by a translation table (`crates/geas-core/src/i18n.rs`).

- The table is `crates/geas-core/assets/i18n/en.tsv`. One line is `Japanese<TAB>English` (a `u` in the third column marks that even a short sentence is replaced regardless of what surrounds it). A newline is `\n`, and `\` is `\\`.
- `{}` is the place of an argument. On the English side, put `{}` (in order) or a number such as `{2}`. Japanese inside an argument is also translated.
- **A sentence not in the table is output in Japanese** (it does not stop). Missing sentences can be found with `crates/geas-core/examples/i18n_missing.rs` (pass one sentence per line on standard input; `--show` shows the English result).
- So as not to break sentences written by the user, a short sentence with few Japanese characters is replaced only when it is a line, a table cell, or delimited by what surrounds it.
- English that goes into strings of generated code uses a form that does not add quotation marks (`”` `’`).

When you add or change wording, after fixing the Japanese sentence, fix the corresponding line of `en.tsv` too (`cargo test -p geas-core i18n` checks duplicates and the number of arguments).
