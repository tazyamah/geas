# 未着手・保留の一覧

人が読む一覧で、強制力は検査器にない。決まったこと（決定）は各 docs に書き、ここは「まだやっていないこと」だけを置く。着手したら消すか、済みに移す。最終更新：2026-10-30。

## 本体の実装

- **geas 本体の Rust 化**（検査器・生成器・CLI。いまは Python で約 9,300 行）。「ちゃんと動くのが先」で、いまは Python のまま進める。生成アプリとサーバー実行部は既に Rust。README の Rust 化予告は残す。
- **raw から convert で境界の値を変換する書き方**。第 1 段（`raw` 型、`require` つきの `convert`、型の `read`、文字位置の `sum`、式の `if`）は実装済み。`check gtin` は、`convert` で同じ判定が書けると確かめたが、組み込みはまだ残している。消すには、画面の固定値の静的確認とブラウザ拡張の事前検査を `read` の変換で動かす必要がある。`trust dangerous`（未検査の `raw` を受けて外へ中継）は実装済み。残り：入れ子の形、`dangerous` の画面でのエスケープ省略（画面に `raw` を出す書き方が決まってから）、`unsafe` を使う場面（いまの生成物には無い）。
- **言語側の標準部品**（ハッシュなど、geas の式で書けない純粋な計算）。`library` の上に、保証つきの定義として載せる方針。未実装。`part` の外部実装は廃止し、`library`（根の言語のライブラリ呼び出し）に置き換えた。

## 「生成時の書き方で保証し、実行時の損失をゼロにする」の議論

方針と決定の記録は [why-spec-and-code-dont-drift.md](why-spec-and-code-dont-drift.md)。1 件ずつ具体例で議論している。

| # | 論点 | 状態 |
|---|---|---|
| 1 | 外の部品・境界確認 | `trust verify／assume` は実装済み（入力の型のみ）。raw から convert の第 1 段は実装済み。`part` の外部実装は廃止し、根の言語のライブラリを呼ぶ `library`（trust 必須、人の保証に出る）に置き換え済み。標準部品は未着手 |
| 2 | 割合の掛け算の桁 | 済み（#78：分母の物理上限と、途中の桁の検査） |
| 3 | 変数で割る割り算 | 済み：割る数が 1 以上と示せるか、`x / d or 0` で 0 のときの値を書く（範囲の宣言と、`if` で止めた先の範囲を使う） |
| 4 | 増え続ける累計（`saturating +=`） | 済み：`+= 式 saturating "理由"`（端で止める）と `+= 式 trust assume "理由"`（届かないと承知）。`update { … += … }` の形には未対応 |
| 5 | 書込適用と同時リクエスト | 直列化は済み（1 リクエスト 1 トランザクションで、直列の保証は DB の書き込みロックが担う。同じ DB ファイルの複数サーバーでも試験あり、panic でも続行）。`storage 保存先 isolation process|store(種類) ["理由"]` で保存先を定義し、保証の範囲を持たせられる。未着手：保存層を契約（trait）として切り出し、別の保存先を足せるようにする。未決：画面の古い値での上書き（版の確認） |
| 6 | 外から入る値の境界確認 | 1 に含めて対応（`trust` で緩められる） |
| 7 | 資源枯渇 | 一部済み：長さを書かない文字列の既定の上限（1,048,576 文字）、本文 16 MiB の上限（413）、JSON の入れ子 64 段。処理が触れる entity だけを保存から読む（定義の `touches`、処理のみ）も済み。worker の本数（`--workers`）と待ち受けアドレス（`--host`）も済み。読み込みの時間切れは部品（tiny_http）に口がないため、nginx などを前に置く前提で docs/server.md に書いた。未着手：問い合わせも同じく絞る。件数の上限は需要が出てから |

提案済みで未着手：途中の算術すべてを区間で示す、`Unproven` を証拠の再利用でなくす、書込の版の確認（画面の古い値での上書きを止める）。任意で、固定容量の生成による Kani の検証（標準の BTreeMap と String では遅すぎた）。

## 動かす確認がまだ無いもの

[language-test-map.md](language-test-map.md) の「まだ無いもの（✕）」と同じ。

- `event` の `external → 処理`（外から渡す入力で動く形）
- `now`・`tz_offset` を使う処理
- MCP を実サーバーに中継して動かす確認

## 検証・生成

- ①（会話で作る仕様書）を別に作る意味の検証。[open-questions.md](open-questions.md) 参照。
- 画面の通しの試験（Playwright）と HTTP の通し試験を、手書きでなく計画書の URL の具体例から生成する構想。
- ユースケースの手順に URL の列を足す。`update`／`destroy` の HTTP 通し試験。
- 手書きの残り（Chrome 拡張、dev の模擬）をなくす。

## 範囲外としたもの

[v0.1.0-scope.md](v0.1.0-scope.md) に理由つきである。同時起動の書き込みの重なり（S7）、par の枝の書き込み、暦の計算（月の加算・曜日・夏時間・祝日）、浮動小数、物理量の単位など。
