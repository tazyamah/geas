# 日本語・英語モード

geas が出す文章は、日本語と英語のどちらでも出せます。**何も指定しないと英語**です（他の人が使うときの既定）。日本語にするには、次のどちらかを使います。

```sh
geas check アプリ.geas --lang ja        # 1 回だけ日本語（--lang=ja でもよい）
export GEAS_LANG=ja                      # いつも日本語（シェルの設定に書いておく）
```

優先順位は `--lang`、`GEAS_LANG`、既定（英語）の順です。`ja`・`en` 以外（`ja_JP.UTF-8`・`en-US` のような書き方は可）は、終了コード 2 で断ります。

## 何が切り替わるか

| 対象 | 切り替わるもの |
|---|---|
| 検査器・構文エラー・CLI の表示 | メッセージ、直し方（hint）、`--json` の `message`・`hint` |
| 生成する仕様書・レビュー画面・各種レポート | 見出し、表の列名、固定の言い回し（`<html lang>` も） |
| 生成する Rust とアプリの部品 | 実行時のエラー文、画面の固定文言（生成したときの言語で固定される） |
| 表示名（`///`） | `@en …` と `@ja …` のうち、いまの言語のもの。無ければ、タグなしの行、最後にもう一方の言語 |

切り替わらないもの：

- **コードの名前と、利用者が書いた文字列**（`///` の本文、画面の文字列、具体例の値など）。仕様書の中では、書いたままの言語で出ます（英語の仕様書に日本語の名前が混ざるのは、そのためです）。英語版の表示名が要るときは、`/// @en Stock count` のように足します。
- **計画書（plan.md）**。突き合わせの読み取りが日本語の見出しに結びついているので、計画書とその雛形（`geas interview`）は、いまは日本語のままです。
- `astdump` と開発用の出力（`rustlib`・`rusthost`）。ほかの道具が読むので、常に日本語のままです。
- ライブラリとして `geas_core` を使うときの既定は日本語です（`geas_core::i18n::set_lang(Lang::En)` で切り替える）。

## しくみ

文言のもとは日本語のまま `crates/geas-core/src` に書いてあり、英語モードのときだけ、出力の直前に対訳表で英語にします（`crates/geas-core/src/i18n.rs`）。

- 対訳表は `crates/geas-core/assets/i18n/en.tsv`。1 行が `日本語<TAB>English`（3 列目の `u` は、短い文でも前後を問わず置き換える印）。改行は `\n`、`\` は `\\`。
- `{}` は引数の場所。英語側は `{}`（順に）か `{2}` のように番号で置く。引数の中の日本語も訳す。
- **表に無い文は、日本語のまま出ます**（止まりません）。足りない文は、`crates/geas-core/examples/i18n_missing.rs` で調べられます（1 行 1 文を標準入力に渡す。`--show` で、英訳した結果を見る）。
- 利用者が書いた文を壊さないよう、日本語の字が少ない短い文は、行・表のセル・前後が区切りのときだけ置き換えます。
- 生成したコードの文字列に入る英語は、引用符を増やさない形（`”` `’`）にします。

文言を足したり直したりするときは、日本語の文を直したら `en.tsv` の対応する行も直します（`cargo test -p geas-core i18n` が、重複と引数の数を確かめます）。
