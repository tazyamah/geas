GEAS / ギアス

AI がコードを書く。
人はコードを読まず、仕様書だけでレビューする。

仕様書とコードが直結合した言語です。仕様書に出ない動きはコードに書けず、言ったとおりに作れているかは、読んで確かめるのではなく検査器が機械で示します。

見本の仕様書を開く 変更点だけの版を見る はじめかた 仕組み English GitHub

進め方

人が読むのは、いつも生成された仕様書だけです。

会話で計画書を作る

AI が一問ずつ聞いて、ユースケースから計画書（Markdown）を作ります。

AI がコードを書く

計画書から .geas を起こします。人はこれを読みません。

仕様書をレビューする

検査し、コードから仕様書を生成して、計画書と突き合わせます。具体例は生成した Rust で実際に動かします。

見本の仕様書

「海外にも売るお店」を題材に、.geas から生成したものです。

FULL

仕様書の全体

ユースケース、画面の遷移、具体例、状態、保存の形、人の保証まで。

開く → DIFF

前の版からの変更と、答えてほしいこと

更新のたびに、人が見るのはここだけ。変わったところと、人の判断が要るところに絞っています。

開く →

保証のしかた

守らせたい約束を重くするほど、保証が強くなります。

仕様書に無い動きは書けない

外への作用、保存、遷移、呼べる人まで、すべて仕様書に出る形でしか書けません。

値の範囲を検査器が示す

計算や書き込みが型の範囲に収まることを、検査器が示します。示せなければエラーです。

生成物は壊れ方も決まっている

生成された Rust は panic につながる構文を持たず、異常は決まった形で返します。
