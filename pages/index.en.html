GEAS

The AI writes the code.
Humans never read it — they review the specification.

Geas binds the specification and the code together. Behavior that does not appear in the specification cannot be written in the code, and whether the code does what was asked is shown mechanically by the checker, not confirmed by reading.

The flow

A human only ever reads the generated specification.

Build a plan by conversation

An AI asks one question at a time and builds a plan (Markdown) from the use cases.

The AI writes the code

It turns the plan into .geas. Humans do not read it.

Review the specification

The code is checked, a specification is generated from it and compared with the plan. The examples are run against the generated Rust.

How it is guaranteed

The heavier the promise you make it keep, the stronger the guarantee.

No behavior outside the specification

External effects, storage, transitions and who may call what can only be written in forms that appear in the specification.

Value ranges are proved by the checker

That calculations and writes fit the type's range is shown by the checker. If it cannot be shown, it is an error.

Generated code fails in a defined way

The generated Rust has no constructs that can panic, and abnormal cases are returned in a fixed form.
